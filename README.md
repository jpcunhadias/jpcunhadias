## About Me

[![LinkedIn](https://custom-icon-badges.demolab.com/badge/LinkedIn-Connect-blue?style=flat&logo=linkedin)](https://www.linkedin.com/in/jpcunhadias)

[![Portfolio](https://custom-icon-badges.demolab.com/badge/Portfolio-Visit-orange?style=flat&logo=github)](https://joaopdias.dev)

I’m a Brazilian **Machine Learning Engineer** based in Cottbus, Germany, focused on building reliable ML systems and bringing models into production.

I’m currently pursuing an **M.Sc. in Artificial Intelligence at BTU Cottbus-Senftenberg**, while expanding my work into LLM applications, retrieval-augmented generation (RAG), vector databases, and applied AI systems.

### Areas of Focus
* **ML Engineering & MLOps:** Experiment tracking, reproducibility, orchestration, CI/CD, testing, and model lifecycle management.
* **Production ML Systems:** APIs, containerized services, deployment workflows, monitoring, and maintainable backend integrations.
* **Data Pipelines:** Data ingestion, transformation, validation, batch processing, and scalable workflows.
* **Applied AI:** NLP, computer vision, LLM applications, RAG, semantic retrieval, and vector search.
* **Cloud & Infrastructure:** GCP, AWS, Docker, and supporting data infrastructure.

### Industry Experience
* **Public Health:** NLP pipelines, medical report classification, OCR automation, model lifecycle management, and production ML infrastructure.
* **Automotive:** Statistical modeling and machine learning on large-scale EV telemetry using PySpark, MLlib, BigQuery, and Vertex AI.
* **Software Products:** NLP, text classification, experimentation, and integration of ML models into existing C# applications.
* **International Analytics:** ETL, APIs, dashboards, cloud data environments, and stakeholder-facing analytics in a UN setting.

### Languages
* **English:** C1 / IELTS 7.5
* **German:** A2
* **Portuguese:** Native
